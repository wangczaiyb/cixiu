# 一针一线 · 绣一点可爱

参考用户提供的刺绣视频制作的中文网页小游戏。六幅原创矢量萌物线稿，以及 Hello Kitty、库洛米、玉桂狗、美乐蒂、布丁狗和帕恰狗六幅角色刺绣线稿。所有画面与亚麻、木绷、针线效果由 Canvas / SVG 本地绘制，无运行时外部依赖。

## 本地运行

需要 Node.js 18 或以上版本，无需安装依赖。

```powershell
npm start
```

浏览器打开 http://127.0.0.1:4173 。

## 玩法

- 按住鼠标或手指，沿图案虚线拖动刺绣。
- 点击“开始慢绣”自动刺绣，可以暂停或选择 1× / 2× / 4×。
- 六种线色、原配色，三种针法，三种绣布颜色。
- “人气角色 / 萌物日常”切换共 12 幅图案；每幅图案分别保存进度。
- 机绣模式包含上下落针、压脚和轻微送料震动；关闭开关可返回手绣。
- 机械落针、回针、马达音效由 Web Audio 实时合成；速度随落针变化，暂停或离开页面立即停机。顶部可静音，线盒下方可调整音量。
- 撤销按钮或 Ctrl / Command + Z 撤销一段针线。
- 每幅图案独立保存进度；收藏最多保留最近 12 幅作品。
- “保存这份小美好”可预览、收藏、下载 PNG，未完成的作品也能保存。
- 进度与收藏仅保存在当前浏览器 localStorage，不跨设备同步。清理浏览器数据会移除它们。
- 画布聚焦后按空格或回车可开始 / 暂停自动刺绣。

## 检查

```powershell
npm run check
```

## 文件

- `dist/`：可直接部署的静态网站。
- `dist/patterns.js`：原创 SVG 图案、线色及绣布。
- `dist/engine.js`：刺绣进度、撤销、存档校验和拖动采样。
- `dist/app.js`：交互、纹理及刺绣渲染。
- `server.mjs`：仅监听本机的静态预览服务器。

这是根据参考玩法独立制作的可玩版本，不包含原视频游戏的源码或素材。人气角色线稿为手工绘制的同人刺绣图案，角色设计参考 [Sanrio 官方角色介绍](https://www.sanrio.co.jp/characters/)。

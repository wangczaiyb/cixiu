# 一针一线 · 绣一点可爱

可自由排版的中文刺绣小游戏：在带针孔与经纬纹理的丝光绣布上，把角色、手写文字和信件一起绣出来。画面由 Canvas / SVG 绘制，针织机声音由 Web Audio 合成；全部运行资源都随项目提供。

## 本地运行

需要 Node.js 18 或以上版本，无需安装依赖。

```powershell
npm start
```

电脑浏览器打开 http://127.0.0.1:4173 ，手机连接同一 Wi-Fi / 局域网亦可访问终端输出的局域网 IP 地址。

## 玩法

- 按住鼠标或手指，沿图案虚线拖动刺绣。
- 点击“开始慢绣”自动刺绣，可以暂停或选择 1× / 2× / 4×。
- 六种线色、原配色，三种针法，三种绣布颜色。
- 27 款人气角色（含轻松熊）和 6 幅原创萌物，可搜索并反复添加。
- 人气角色按照原型图片的真实颜色与形状生成密集填绣针脚，保留脸型、表情和配色；针脚具有绒线阴影与丝线高光。
- 大幅绣布默认摆放 5 个角色，最多容纳 20 个图案或文字元素。支持拖动、独立缩放、旋转、复制、移除和自动整理。
- 自定义中英文手写刺绣，支持 120 字、换行分段、左中右对齐、行宽和行距，以及棉线 / 毛线纹理与随性手写程度。
- 绣信模板把称呼、正文和落款 / 日期分别加入绣布，图案和文字可以自由混排。
- 机绣模式包含上下落针、压脚和轻微送料震动；关闭开关可返回手绣。
- 机械落针、回针、马达音效由 Web Audio 实时合成；速度随落针变化，暂停或离开页面立即停机。顶部可静音，线盒下方可调整音量。
- 撤销按钮或 Ctrl / Command + Z 撤销一段针线。
- 排版和针线进度自动保存在浏览器，移动或缩放元素会保留已有针线。收藏最多保留最近 12 幅作品。
- “保存这份小美好”可预览、收藏、下载 PNG，未完成的作品也能保存。
- 进度与收藏仅保存在当前浏览器 localStorage，不跨设备同步。清理浏览器数据会移除它们。
- 画布聚焦后按空格或回车可开始 / 暂停自动刺绣。

## 检查

```powershell
npm run check
```

## 文件

- `dist/`：可直接部署的静态网站。
- `dist/patterns.js`、`*-patterns.js`：角色与原创 SVG 针路。
- `dist/editor-app.js`：编辑、刺绣、信件、收藏和图片导出。
- `dist/composition.js`：独立元素变换、针线状态与几何采样。
- `dist/renderer.js`：丝光孔眼绣布、针脚层次与压脚动画。
- `dist/text-strokes.js`、`dist/latin-strokes.js`：确定性的中英文手写针路。
- `dist/assets/hanzi/`：9,574 个汉字的本地笔画分片和完整来源许可。
- `server.mjs`：仅监听本机的静态预览服务器。

这是根据参考玩法独立制作的可玩版本，不包含原视频游戏的源码或素材。角色原图与来源记录保存在 `dist/assets/characters/`，运行时转换为逐针填绣；角色及原图的权利归各自权利方。原始素材保持不变，图片分割、留白整理和线材效果均在游戏画布中计算。

汉字中心线来源与修改说明见 [ATTRIBUTION.md](dist/assets/hanzi/ATTRIBUTION.md)，数据遵循随附的 Arphic Public License。

## Render 部署

本项目直接发布 `dist/` 静态资源，不需要 Node 服务、数据库、环境变量或安装运行依赖。

| 配置 | 值 |
| --- | --- |
| 服务类型 | Static Site |
| 分支 | `main` |
| 根目录 | 仓库根目录 |
| 构建命令 | `npm run check` |
| 发布目录 | `dist` |
| 自动部署 | On Commit |

测试通过后 Render 发布现有静态文件。浏览器进度与收藏依照站点域名分别保存。
